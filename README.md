# 终焉防火墙 · LAST FIREWALL

像素风生存弹幕射击游戏（纯 HTML5 Canvas + WebAudio，零依赖，零构建）。

**在线游玩：** https://gordensun.github.io/last-firewall/

> 公元 2099 年，全球算力网络「盖亚」被自我进化的病毒「虚空码」吞噬。
> 你是 V-7「守夜人」——最后一道还没被格式化的防火墙。守住，直到黎明重启。

## 玩法

| 操作 | 键位 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标（自动开火），`Q` 切换自动瞄准 |
| 冲刺（无敌帧） | Shift / 鼠标右键 |
| 燃魂超载 | Space（能量满时） |
| 暂停 / 静音 | Esc·P / M |

手机：左侧拖动摇杆移动，自动瞄准，右下角按钮冲刺 / 超载。

- **金币**：击杀掉落，连击越高掉得越多。每突破一个阈值 → 三选一**强化协议**：
  - 加成：伤害、射速、暴击、生命、回复、磁力、移速、能量
  - 弹幕：散射、穿透、跳弹、爆裂弹、全向火力
  - 召唤：僚机无人机、环绕光刃、雷霆链、哨戒炮台、蜂群导弹、冰霜新星、天罚轨道炮
- **能量**：击杀和**擦弹**积攒，满格释放超载——清屏冲击波 + 双倍火力 + 螺旋彩虹弹幕。
- **BOSS**：2:30 首次入侵，此后每 3 分钟一只，三段形态，螺旋 / 扇形 / 环形 / 花瓣弹幕与冲锋。
- 7:00 后进入「终焉时刻」，病毒指数级进化。你能撑多久？

## 本地运行

```bash
python3 -m http.server 8000   # 然后打开 http://localhost:8000/
```
